# Saborê

Aplicativo mobile de receitas feito em Flutter, desenvolvido individualmente em etapas:

1. **Interface**: tela principal com identidade visual.
2. **Pesquisa**: campo de busca com validação.
3. **Telas**: listagem, detalhes e favoritos com navegação.
4. **Entrega final**: integração com a API [DummyJSON Recipes](https://dummyjson.com/docs/recipes).

## Como rodar

```bash
flutter pub get
flutter run
```

## Testes

```bash
flutter test
```
